# OIBSIP-DataScience-Task3-EmailSpamDetection
# 📩 Email Spam Detection using Machine Learning

## 📌 Project Overview
This project focuses on classifying text messages as **Spam** or **Ham (Not Spam)** using Natural Language Processing (NLP) and machine learning techniques. TF-IDF vectorization converts text into numerical features that help models identify spam messages.

## 🎯 Objective
To build and evaluate machine learning models that can automatically detect unwanted or suspicious messages based on their text content.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **NLP Technique:** TF-IDF Vectorization
- **Environment:** Google Colab / Jupyter Notebook

## 🤖 Machine Learning Models
- Multinomial Naive Bayes
- Logistic Regression

## 📂 Dataset
The project uses the **SMS Spam Collection Dataset**, which contains text messages labeled as:
- **Ham:** Legitimate messages
- **Spam:** Unwanted or promotional messages

Dataset source: [Kaggle – SMS Spam Collection](https://www.kaggle.com/datasets/uciml/sms-spam-collection)

## ⚙️ Project Workflow
1. Load and explore the dataset.
2. Clean the text data and remove duplicate messages.
3. Analyze message distribution and text length.
4. Convert messages into numerical features using TF-IDF.
5. Train Multinomial Naive Bayes and Logistic Regression models.
6. Evaluate model performance using accuracy, precision, recall, and F1-score.
7. Compare the models and test predictions on sample messages.

## 📊 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## ✅ Conclusion
This project demonstrates how NLP and machine learning can be used to identify spam messages. The performance of both models is evaluated and compared to understand their effectiveness in classifying messages.
